# Symbol reuse (`.qsym`)

- `export_symbol_to_qsym` writes one component's embedded symbol as a standalone `.qsym` file for reuse across schematics or external symbol libraries.
- `add_component_from_qsym` places a `.qsym` symbol into a schematic with a new reference designator (full drawing, pins, type, and library file embedded).
