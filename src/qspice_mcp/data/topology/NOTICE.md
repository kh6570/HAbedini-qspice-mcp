# Topology knowledge pack — attribution

The continuous-conduction-mode (CCM) design relationships and control notes in this
pack restate standard, long-established switched-mode power-converter theory.

The theoretical framing is informed by, and cited to:

> J. Marcos Alonso, *Modelling, Control and Simulation of DC-DC Converters*,
> ISBN 979-8278321743, Amazon KDP, 2025.
> Companion repository:
> <https://github.com/marcosalonsoelectronics/Modelling-Control-and-Simulation-of-DC-DC-Converters>

Used as a cited theoretical reference with the author's permission.

**Clean-room statement.** Every file in this directory is repo-owned and was written
from first principles using textbook CCM converter equations. No schematic (`.asc`,
`.qsch`), netlist, source-code, or document file from the referenced repository is
copied, adapted, or redistributed here. The blueprints describe topologies and design
equations only; they are not reproductions of any third-party work.
